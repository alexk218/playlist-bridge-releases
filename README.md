# Playlist Bridge releases

Public downloads and update feeds for Playlist Bridge, a standalone macOS app that prepares Spotify playlists and local recordings for rekordbox.

## Downloads

No signed public release is available yet. Installers will appear on the [Releases page](https://github.com/alexk218/playlist-bridge-releases/releases) after signing, notarization, and upgrade testing.

## Update channels

- Stable: `channels/stable.json`
- Beta: `channels/beta.json`

The channel files will be created when a tested release is promoted. App updates are downloaded and installed only after the user chooses to do so. The first updater-enabled version requires a manual installation.

This repository contains release information and installers. The app's source code is maintained separately.
